# Как контрибьютить

1. Для заметных изменений — сначала issue, потом PR: обсудим до того,
   как ты потратишь вечер.
2. Ветка от `master`, PR в `master`. CI (typecheck + тесты + сборка)
   должен быть зелёным.
3. Логика ядра (`src/logic`) меняется только вместе с vitest-тестами
   на граничные случаи.
4. Прочти [CLAUDE.md](CLAUDE.md) — там инварианты, которые нельзя ломать
   (append-only логи, детерминизм неба, «одно ядро — все головы»).
   Файл читают и люди, и агенты.
5. Язык UI-текстов и комментариев — русский; технические термины в оригинале.
6. Формат `store.json` — публичный контракт: несовместимое изменение
   обязано нести миграцию.

Лицензия проекта — AGPL-3.0; отправляя PR, ты соглашаешься лицензировать
свой вклад под ней.
