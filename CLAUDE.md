# CLAUDE.md — Stargaze

RPG-интерфейс над реальной жизнью: навыки — галактики, звёзды — освоенные
умения, квесты — задачи с XP и наградами. Одно ядро (`src/logic`) — три
головы: веб (`src/`), CLI (`cli/`), HTTP API (`server/`).

## Команды

- `npm run dev` — dev-сервер (Vite)
- `npm run serve` — сборка + запуск веб и API поверх `~/.stargaze/store.json`
- `npm run build` — сборка веба; `base: './'` — пути относительные, сборка
  раздаётся из любой подпапки. С диска (`file://`) не открывается: браузер
  блокирует модульный скрипт по CORS — нужен любой HTTP-сервер
- `npm test` — vitest; `npm run typecheck` — строгий tsc — гонять перед коммитом
- `npm run build:cli` / `npm run build:server` — CJS-бандлы `dist-node/`

## Инварианты (не ломать)

- **`xpLog` и `ledger` — append-only логи и единственные источники правды.**
  Уровни, баланс искр, плотность привычек вычисляются (`logic/selectors.ts`,
  `logic/xp.ts`, `logic/recurring.ts`, `logic/sparks.ts`); денормализованных
  счётчиков нет.
  Откат = компенсирующее событие (отрицательный amount / `reversal`), не удаление.
- **Раскладка неба детерминирована** (`logic/layout.ts`): позиции — seeded PRNG
  от id сущностей. Никакого `Math.random()` в рендере.
- **История неба — проекция, не снимок** (`logic/timeline.ts`): прошлое —
  `skyAsOf(store, день)`, store не меняется; раскладка в режиме истории всегда
  считается по сегодняшнему набору — время управляет только видимостью, светом
  и уровнями.
- **Одно ядро — все головы**: новая функциональность сначала в `src/logic`,
  потом в головы. Головы не дублируют логику. Машинные срезы чтения
  (`cli … --json` ≡ `GET /api/<команда>`) — `logic/views.ts`; их JSON —
  публичный контракт (`API.md`), «сегодня» приходит в срез параметром.
- Сущности из payload (`add*`/`update*`/`proposeQuest`) попадают в store только
  по белому списку ключей типа (`logic/entityKeys.ts`, `satisfies Record<keyof T,
  true>`): лишнее молча отбрасывается, `validateStore` лишние ключи намеренно
  не ловит. Исключение — удалённое поле формата `daysOfWeek`: проходит насквозь
  ради 422. Новое поле типа — строка в белом списке, иначе не скомпилируется.
- Запись store на диск — только через `logic/storage.ts` (лок + tmp+rename +
  validateStore — невалидное не пишется никем).
- «Сегодня» игры — пояс мира `store.tzOffsetMin` (минуты от UTC; нет поля —
  UTC+7): `gameTzOffset` / `dayInGameTz(iso, offsetMin)` в `logic/sparks.ts`,
  офсет — обязательный параметр, у кого есть store — берёт из него. Меняется
  только действием `setGameTz` (CLI `stargaze tz`). День события пишется в лог
  при создании, из ts не выводится и при смене пояса не пересчитывается.
- Привычки (`repeating`) — без расписания и стриков: отметка за любой прошедший
  день, искры — только за сегодня/вчера (`earnWindowOk`), отметка в будущее —
  no-op ядра (API отвечает 422).
- **Формат store (v4) — публичный контракт**: несовместимое изменение формата
  обязано нести миграцию — новую ступень в `migrateStore` (`logic/migrate.ts`,
  единственное место миграций). Порядок на любом входе чужих данных:
  parse → `migrateStore` → `validateStore`. Совместимое добавление
  (необязательное поле, отсутствие = прежнее поведение, старые версии его не
  отвергают) идёт без миграции и без смены `version` — пример `tzOffsetMin`.
- Формулы уровней: навык `100 + 50·(n−1)`, персонаж `300 + 150·(n−1)` —
  менять только вместе с тестами.
- Ответы `POST /api/action` (полный список — `API.md`): 400 — неверная форма
  payload (`actionShapeError`, `logic/gates.ts`; форма выводится из `Action`
  union); 422 — гейты: активные подквесты эпика, нехватка искр, незажжённая
  звезда-якорь, перенос дедлайна в прошлое, `archiveSkill` с активными
  контрактами, у `completeQuest` ещё нет итога, открытый DoD без `force`,
  отметка привычки наперёд и нечитаемый `ts` у контракта со сроком
  (`completeQuestRefusal` — зеркало редьюсера), плюс отказ `validateStore`.
  `null` в необязательном поле payload — «поля нет» (`dropNullOptionals` до
  редьюсера). Прочие no-op, в том числе идемпотентные повторы, —
  200 с `Stargaze-Applied: 0`, запись — `1` (по содержимому, не по ссылке).
  Поля payload — `questId`/`skillId`/`itemId` по типам `Action` union, не `id`.
  GET-срезы: 400 кривой параметр / 404 / 409 неоднозначный префикс / 503 нет store.

## Правила

- Логика ядра меняется только с vitest-тестами на граничные случаи.
- Язык UI-текстов — русский; технические термины в оригинале.
- Без UI-библиотек и Tailwind: тема в `src/index.css`, небо — SVG руками.
- Состояние: `useReducer` + localStorage (`stargaze.v4`); без Redux/Zustand.
- Legacy-якоря `questlog.*` и `stargaze.v3` (localStorage), env-фолбэки
  `QUESTLOG_*` читаются вечно — не переименовывать и не удалять.
