# Changelog

Версии — [semver](https://semver.org/lang/ru/). Формат store.json —
публичный контракт: несовместимое изменение формата обязано нести миграцию.

## [0.2.0] — 2026-08-26

Первый публичный релиз.

- Небо навыков: галактики, деревья звёзд, ранги D–S, зажигание звёзд руками
  (с evidence), детерминированная раскладка.
- Квесты: повторяющиеся привычки и контракты (short/mid/long) с карточкой —
  описание, «зачем», Definition of Done, ресурсы, итог при сдаче.
- Экономика искр: награда за сдачу вовремя, капание за просрочку, переносы
  дедлайнов с квотой, вишлист (разовые и многоразовые награды, big-награды
  по звезде-якорю), трек накоплений.
- Одно ядро — три головы: веб, CLI, HTTP API.
- `stargaze serve` — локальный запуск одной командой; первый старт создаёт
  демо-мир.
- Docker-образ: `ghcr.io/ilia-pluzhnikov/stargaze`.

В планах: MCP-сервер для агентов, английский интерфейс, npm-пакет.
