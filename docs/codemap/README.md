# Карта кода Stargaze

Три артефакта, которые всегда собираются вместе из одной модели:

| файл | что это |
|---|---|
| `codemap.html` | интерактивная схема: 20 модулей, 63 связи, 5 сквозных потоков. Самодостаточна — открывается двойным кликом, без сети и CDN |
| `codemap.json` | те же данные машиночитаемо: узлы (путь, роль, точки входа, тесты, инварианты, доказательства), рёбра (`imports/calls/reads/writes/publishes/subscribes`), потоки (триггер → шаги → итог) |
| `codemap.lock` | commit, состояние working tree, время генерации, scope, исключения, алгоритм и отпечаток каждого модуля |

## Команды

```bash
node docs/codemap/build.mjs          # перегенерировать все три файла
node docs/codemap/build.mjs --check  # только сверка: что изменилось с прошлой карты (exit 1, если устарела)
```

## Как устроено

- `model.mjs` — **единственный файл, который правится руками**: модули, связи,
  потоки, инварианты. Каждое утверждение снабжено `evidence` — пара
  «путь + фрагмент исходника».
- `build.mjs` — валидирует модель (пути в git, символы буквально встречаются в
  файлах, рёбра и шаги потоков ссылаются на существующие узлы, исходник
  принадлежит одному модулю), считает отпечатки, сверяется с прежним lock и
  пишет три артефакта. Не прошло — не записывает ничего.
- `html.mjs` — рендер схемы. Ярус модуля задан в модели (архитектурный уровень),
  порядок внутри яруса — барицентр-проходы, режущие пересечения рёбер.

Отпечаток модуля: `sha256` от отсортированного списка
`<путь>\0sha256(содержимое файла)` по его исходникам и тестам. Меняется файл —
меняется отпечаток — модуль попадает в «изменился с прошлой карты» и получает
оранжевую метку в HTML.

## Что карта сознательно не делает

- Не парсит AST: связи описаны на уровне модулей, а не символов. Точный
  «кто вызывает эту функцию» — это `grep`/LSP, а не карта.
- Не покрывает `docs/`, конфиги тулчейна и сборочные артефакты (см.
  `excluded` в `model.mjs`).
- Не выдумывает: связь, которую нечем подтвердить фрагментом исходника,
  помечается `unknown`. Внешние системы (`store.json` на дроплете,
  `localStorage`) не имеют путей в репозитории — их доказательства косвенные,
  через код, который к ним обращается.
